# 🌾 AgroLedger – Farm, Expense & Profit Manager

**AgroLedger – Farm, Expense & Profit Manager** is a lightweight, offline-first, single-file HTML web application built for farmers, farm managers, and agricultural partnerships worldwide. It runs directly in any modern mobile or desktop browser with zero server setup, helping you manage field operations, cultivation costs, harvest weight sales, buyer advances, and net profit/loss in one place.

### ✨ Key Features
- **🌱 Farm, Field & Crop Organization:** Manage multiple landowners, fields, and seasonal crop cycles from a clean dashboard.
- **💸 Cultivation Expense Tracking:** Log seeds, fertilizers, crop protection, labor, irrigation, machinery, and miscellaneous costs by crop and date.
- **🤝 Partnership & Land Lease Splits:** Automatically calculate shared expenses, revenue, and net profit/loss for joint farming or fixed-lease agreements.
- **⚖️ Harvest Weight Sales & Deductions:** Fast bag/unit weight entry with automatic totals, packaging/tare weight, impurity deductions, unit conversions, and trade discounts.
- **🏪 Buyer Advance Ledger & Printable Bills:** Record advance payments from buyers/traders and generate clean, print-ready statements and invoices.
- **💾 100% Offline & JSON Backup:** All data is stored locally in your browser's `localStorage` with one-click JSON export and restore.

### 🚀 Getting Started
1. Download `index.html` from this repository or open the hosted **GitHub Pages** URL in your browser.
2. On mobile browsers (Chrome/Safari), select **Add to Home Screen** to use AgroLedger like a standalone app—even without an internet connection.
